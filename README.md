# HLS Segment Downloader (Chrome 확장)

**한국어** | [English](README.en.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

웹페이지에서 재생되는 HLS(`.m3u8`) 스트림을 자동 감지하고, 조각(세그먼트)을 병렬로 받아 **MP4 파일 하나로** 합쳐 저장하는 Chrome/Edge 확장 프로그램입니다. 영상과 음성이 별도 트랙으로 나뉜 스트림도 자동으로 합칩니다.

## 설치 (개발자 모드)

1. 이 저장소를 내려받습니다.
2. Chrome에서 `chrome://extensions` → 우측 상단 **개발자 모드** ON
3. **압축해제된 확장 프로그램을 로드합니다** → 저장소 루트 폴더(`manifest.json`이 있는 곳) 선택
4. (Edge는 `edge://extensions`에서 동일)

## 사용법

1. 영상이 있는 페이지에서 **영상을 재생**합니다. m3u8 요청이 감지되면 아이콘에 숫자 배지가 뜹니다.
   - 이미 재생 중이었다면 새로고침 후 다시 재생하세요(확장 설치 이전 요청은 감지할 수 없습니다).
2. 확장 아이콘 클릭 → 감지된 스트림의 **다운로드** 클릭
   - `master.m3u8`(화질 목록)과 `index.m3u8`(실제 세그먼트 목록)이 함께 잡히는 경우가 많습니다. 보통 master를 고르면 화질을 선택할 수 있습니다.
   - URL을 직접 알고 있으면 팝업의 **URL 직접 입력**을 사용하세요. 이때 Referer는 영상이 있던 페이지 주소를 넣는 것이 좋습니다.
3. 새 탭에서 화질 / 음성 트랙(여러 개일 때) / 파일명 / 동시 연결 수를 정하고 **다운로드 시작**
   - 진행 단계: 영상 다운로드 → (별도 음성이면) 음성 다운로드 → MP4 변환
4. 완료되면 저장 위치를 묻는 창이 뜹니다. **다운로드 중에는 탭을 닫지 마세요.**

## 동작 방식

| 단계 | 구현 |
| --- | --- |
| 감지 | `webRequest`로 탭의 요청을 관찰. URL이 `.m3u8`로 끝나거나 응답 `Content-Type`이 HLS인 요청을 기록하고, 그때의 **Referer**도 함께 저장 |
| 헤더 재현 | CDN의 핫링크 차단(Referer/Origin 검사)을 통과하기 위해 `declarativeNetRequest` 세션 규칙으로 **다운로드 탭의 요청에만** Referer/Origin을 원래 페이지 값으로 설정 |
| 파싱 | 마스터(화질 목록) / 미디어(세그먼트) 플레이리스트, `EXT-X-KEY`, `EXT-X-MAP`(fMP4), `EXT-X-BYTERANGE` 지원 |
| 다운로드 | 동시 N개 병렬 요청, 세그먼트별 지수 백오프 재시도, 순서 보장 기록, 메모리 사용 상한(앞서 받는 개수 제한) |
| 복호화 | `METHOD=AES-128`은 WebCrypto(AES-CBC)로 자동 복호화. IV가 없으면 스펙대로 미디어 시퀀스 번호 사용 |
| 임시 저장 | 세그먼트를 RAM이 아닌 **OPFS(브라우저 전용 디스크 영역)** 에 트랙별로 이어 기록 → 수 GB 영상도 메모리 부담 없음 |
| MP4 변환 | [Mediabunny](https://github.com/Vanilagy/mediabunny)로 **재인코딩 없이 컨테이너만 MP4로 변환(remux)**. 별도 음성 트랙은 이 단계에서 영상과 합침. 화질 손실 없고 빠름 |
| 저장 | `chrome.downloads`로 저장 후 임시 파일 삭제 |

## 출력 형식

항상 `.mp4`(H.264/H.265 + AAC 등 원본 코덱 그대로)로 저장합니다.

- 입력 세그먼트: MPEG-TS, fMP4, packed audio(ADTS `.aac`) 지원
- 영상·음성 분리 스트림(`EXT-X-MEDIA TYPE=AUDIO`): 선택한 음성 트랙을 받아 하나의 MP4로 합침
- 만에 하나 MP4 변환이 실패하면 받은 데이터를 버리지 않고 원본 형식(`.ts`)으로 저장하고 사유를 표시합니다.
- 변환 중 원본+MP4가 잠시 동시에 존재하므로 **영상 크기의 약 2배 디스크 여유 공간**이 필요합니다.

## 지원하지 않는 것 (의도적 / 현재 한계)

- **DRM 보호 콘텐츠** (Widevine, FairPlay, PlayReady, `SAMPLE-AES`): 감지되면 다운로드를 거부합니다. 넷플릭스·디즈니+·티빙 등 유료 OTT는 대부분 여기에 해당하며, 이를 우회하는 기능은 넣지 않습니다.
- **라이브 스트림**: 다운로드 시점의 플레이리스트에 있는 구간만 저장합니다(녹화 기능 없음).
- 광고 삽입 등으로 타임스탬프가 중간에 리셋되는(`EXT-X-DISCONTINUITY`) 스트림은 해당 지점에서 싱크가 어긋날 수 있습니다(경고 표시).
- 쿠키·토큰이 짧은 시간 후 만료되는 사이트는 오래 걸리는 다운로드 중간에 403이 날 수 있습니다.

## 개발

```bash
npm test   # 파서·다운로더·MP4 변환 단위 테스트 (Node 20+, 설치할 의존성 없음)
```

```
manifest.json
src/
  background.js        # m3u8 요청 감지 (서비스 워커)
  popup.html/js        # 감지 목록 UI
  downloader.html/js   # 화질 선택·진행률·저장 UI, Referer 규칙 설치
  lib/m3u8.js          # 플레이리스트 파서
  lib/hls-downloader.js# 병렬 다운로드·재시도·AES-128 복호화·순서 보장 기록
  lib/opfs-sink.js     # OPFS 임시 파일
  lib/remux.js         # TS/fMP4/ADTS → MP4 remux, 영상+음성 합치기
  vendor/mediabunny/   # Mediabunny 1.61.3 (MPL-2.0), 수정 없이 번들 파일 그대로 포함
tests/                 # fixtures/ 에 짧은 테스트용 TS/AAC 파일
```

## 주의

본인이 저작권을 갖고 있거나 다운로드가 허용된 콘텐츠에만 사용하세요. 저작권자의 허락 없는 영상의 저장·배포는 저작권법 위반이 될 수 있으며, 사용 책임은 사용자에게 있습니다.
